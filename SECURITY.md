# Public-materials policy

Publish only reviewed project descriptions and explicitly approved screenshots. Never copy an application folder, Git history, private README, credentials, personal dataset, biometric data, reports, debug logs or administrator interface into this showcase.

App builds (APKs) are published only as GitHub Release assets, never committed to the repository. Before release, each build is checked for embedded API keys, tokens and private endpoints. A build that contains a secret is held back until it has been rebuilt without it, and the key is rotated.

Security findings and personal data must not be posted in public comments or pull requests. Contact the owner through an independently verified private channel; request a contact method without disclosing details if needed.

Source privacy is an access boundary, not a security certification. It does not remove existing public copies or override third-party licenses. Exposed credentials require revocation or rotation, not merely a visibility change.
